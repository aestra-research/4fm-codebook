# Codebook Version Comparison

## Version 1.3 (EA_LT_4FMs_Codebook)

### Strengths:
- **Clear metadata structure** with version history tracking
- **Core concepts section** with detailed definitions (inner consent, dialogical structure, existential analysis definition, motivation, being-in-the-world, dialogical being, provocation)
- **Motivational process** clearly articulated (3 steps: recognizing, harmonizing, inner consent)
- **Structure of will** with 4 elements comprehensively described
- **Four fundamental motivations** with detailed breakdowns
- **Four fundamental realities** section explicitly connecting realities to FMs
- **Loss of meaning categories** (loss of value, orientation, relations)
- **Meaning characteristics** (objective, relative, subjective, appellative)
- Good citation practices with source quotes
- Comprehensive notes section
- Contains about 1,008 lines of structured content

### Unique Features:
- Explicit version history (1.0, 1.1, 1.2, 1.3)
- Source notes explaining duplicate sources
- Note on person omission in motivational process
- Four fundamental realities as separate section
- Meaning characteristics as standalone section

- **Personal existential analysis process** (3 steps)

### Unique Features:

## Key Differences Summary

### Organizational Structure:
- **v1.3**: Core concepts → Motivational process → Structure of will → FMs → Four realities → Loss of meaning
- **v2.0**: Theoretical framework → FMs (highly structured) → Additional frameworks → Application guidelines
- **v3.3**: Metadata → EA definition → Theoretical foundation (extensive) → FMs → Process → Structure of will → Applications → Coding guidelines

### Citation Practices:
- **v1.3**: Inline citations with quotes
- **v2.0**: Supporting quotes with page numbers
- **v3.3**: Multiple source quotes showing consistency, source_id system

### Practical Application:
- **v1.3**: More theoretical, less coding guidance
- **v2.0**: Most structured for coding with application guidelines and exclusion criteria
- **v3.3**: Comprehensive theory + detailed coding guidelines

### FM Detail Level:
- **v1.3**: Comprehensive but less systematically structured
- **v2.0**: Most consistent structure across all 4 FMs
- **v3.3**: Most detailed with multiple quotes but less consistent structure
