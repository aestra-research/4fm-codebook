## The Four Fundamental Motivations

### FM1: Being in the World
**Question:** "Can I be?"  
**Domain:** Dealing with conditions and possibilities  
**Needs:** Protection, Space, Support

### FM2: Life and Relationship
**Question:** "Do I like to live?"  
**Domain:** Feeling and valuing life  
**Needs:** Relationship, Time, Closeness

### FM3: Being Oneself / Authenticity
**Question:** "May I be myself?"  
**Domain:** Being just and authentic  
**Needs:** Attention, Justice, Value

### FM4: Meaning and Future
**Question:** "For what is it good?"  
**Domain:** Meaning in wider context  
**Needs:** Field of activity, Structural coherence, Future value

## Quick Start: Using the Codebook

### For Coding Interview Data

1. **Start here:** Read `fundamental_motivations` section
2. **Understand:** Each FM's central question and needs
3. **Apply:** Match participant testimony to FM indicators
4. **Use:** Coping reactions to identify when needs aren't met
5. **Reference:** Application guidelines for coding principles

### For Understanding Theory

1. **Start here:** Read `theoretical_foundation` section
2. **Deepen:** Review `core_concepts` for key definitions
3. **Connect:** Study `meaning_framework` for integration
4. **Apply:** Read `motivational_process` (3 steps)
5. **Expand:** Review `applications_beyond_therapy`

### For Assessment/Clinical Work

1. **Start here:** Each FM's `assessment_questions`
2. **Evaluate:** Check which existential needs are met/unmet
3. **Identify:** Look for coping reactions when blocked
4. **Track:** Use temporal analysis (before/during/after)
5. **Plan:** Address needs systematically through FMs
